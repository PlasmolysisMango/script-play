# Script-Play UI 设计规范

## 何时使用

- 新增或重做页面、组件、布局
- 移动端/平板/桌面多端适配，或收到「按钮大小不一 / 太乱 / 太多说明」这类反馈
- 审查视觉一致性、可达性、文案

## 设计立场（来自 frontend-design）

这是一个围着一张桌子读本、发言、搜证、投票的工具，不是 SaaS 仪表盘。视觉方向取自「卷宗」：案卷编号、页边竖线、对白排版、暗房台灯。**大胆只花在一个地方**——二级面板的卷宗感（左侧 accent 竖线 + 编号），其余全部安静。

反套话检查（命中任一条就要改）：
- 一排同款圆角卡片 + 同一个柔和阴影 + 渐变洗底
- 全大写、宽字距的英文小标题（`uppercase tracking-wider`）压在每段标题上
- 每个区块都做 fade-and-slide-up 入场，每张卡片都挂 hover 上浮
- 标题里单独强调一个词（斜体/换色）、`01 / 02 / 03` 编号装饰
- 「A · B · C」式点缀串、按钮尾部统一挂 `→`

## 令牌（来自 theme-factory）

四套主题：`night` / `light` / `paper` / `forest`，全部通过 `<html data-theme>` 切换，定义在 `web/src/index.css` 的 `:root` 块里。

- **只允许语义令牌**：`bg-page` `bg-ink` `bg-panel` `border-line` `text-strong` `text-slate` `bg-accent` `text-on-accent` `bg-warm`。禁止 `bg-[#...]`、`text-white`、`bg-slate-800` 这类绕过主题的字面量。
- 语义色分工：`accent` = 当前/可操作；`warm` = 主持人、待修复、限时压力；`emerald` = 完成/在线；`rose` = 失败/危险。
- 新增一套主题时：只加变量块，不改组件；四个块必须覆盖同一组键。
- 对比度底线：正文与底 ≥ 4.5:1，大字号/图标 ≥ 3:1；每套主题都要单独看，浅色主题最容易掉。

## 排版与尺寸

- 字体：正文用系统中文无衬线；座位号、房间码、时间戳、线索编号用 `ui-monospace`。**不引入外部字体**（离线部署）。
- 层级用字号 + 字重 + 留白，不用全大写英文。
- 间距用 8 的倍数：`gap-2/3/4/5`，卡片内边距桌面 `p-5`、手机 `p-4`。
- 触控目标：手机 ≥ 44px，桌面 ≥ 36px；同一行里的按钮必须等高（用 `.btn` / `.nav-item` / `.icon-btn`，不要各自写 padding）。
- 文本容器必须能收窄：`flex` 里的长标题配 `min-w-0 truncate`，网格用 `grid-cols-1` + `lg:grid-cols-[固定_minmax(0,1fr)]`，否则移动端横向溢出。

## 布局骨架

```
≥1280px  对局：角色本 | 时间线(主) | 行动/局面
≥1024px  大厅/房间/工作台：主内容 | 侧栏(320–340)
<1024px  单栏，顺序按“先看，再动”：时间线 → 输入/行动 → 参考信息(角色本、局面)
```

- 一屏只有一个主行动；次行动降级为 ghost。
- 手机端导航允许换行成独立一行并横向滚动，但每个入口高度必须一致。
- 状态用「圆点 + 词」，不用整块彩色底。

## 文案

- 去掉解释性长段落：一句话留在版面上，细节进 `Hint`（`?` 悬浮/点击）。状态型信息（断开、无音色、限时）不许藏进 `?`，要留在明面上。
- 动词开头、句中不加句号：`保存剧本`、`加入房间`、`开始对局`；同一个动作在整条流程里叫同一个名字（按钮「发布」→ 提示「已发布」）。
- 错误说清「发生了什么 + 怎么修」，不道歉、不拟人。
- 空状态是邀请，不是感慨：一句话 + 一个可点的下一步。

## 工作流（两遍法）

1. **勘察**：截图或量 DOM（375/390、768、1024、1440），记下偏差点：尺寸不齐、溢出、说明文字堆砌、硬编码颜色。
2. **计划**：写清色彩（4–6 个语义角色）、字体角色、布局线框、原则；对照上面的反套话清单自查一遍，改掉"任何同类项目都会这么写"的部分。
3. **实现**：优先改共享层（`index.css` 的组件类、`components/ui.tsx`），再改页面；页面里不新增一次性样式。
4. **验收**：重新截图对比；`npx tsc --noEmit` + `npm run vitest` 必须干净；四个主题各看一遍。

## 审查清单

- [ ] 没有绕过主题的字面颜色
- [ ] 同一区域按钮高度一致（手机 44 / 桌面 36）
- [ ] 390px 宽无横向溢出（`scrollWidth === clientWidth`）
- [ ] 长说明在 `Hint` 里；状态信息在明面上
- [ ] 标题不是全大写英文点缀
- [ ] 卡片阴影/圆角不是"全站同一个值"
- [ ] 键盘可达：focus-visible 可见，`aria-current`/`aria-pressed` 正确
- [ ] 减少动效偏好下不抖动（`prefers-reduced-motion`）
