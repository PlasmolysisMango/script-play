# 参考：令牌、组件与三个视口线框

## 1. 语义色板（以 night 为例，四套主题同构）

| 角色 | 令牌 | night | 用在哪 |
|---|---|---|---|
| 页面底 | `--page` | `#0B1020` | 全屏背景 |
| 内凹区 | `--ink` | `#0B1020` | 输入框、代码块、嵌套区 |
| 面板 | `--panel` | `#141B31` | 卡片、侧栏 |
| 分隔 | `--line` | `#25304D` | 边框、网格线 |
| 当前/可操作 | `--accent` | `#7C9CFF` | 主按钮、当前步骤、焦点环 |
| 主持人/压力 | `--warm` | `#F0B26B` | 主持人标签、限时、待修复 |
| 强调字 | `--strong` | `#FFFFFF` | 标题、关键数字 |

theme-factory 的「一套主题 = 一组命名色 + 一对字体」在这里落成：主题是**变量块**，字体是**角色约定**（正文系统无衬线、数据等宽），不引入外部字体。

## 2. 组件类（`web/src/index.css`）

| 类 | 用途 | 尺寸约束 |
|---|---|---|
| `.sheet` | 二级面板（卷宗页）：左侧 3px accent 竖线 | `p-4 sm:p-5` |
| `.card` | 主面板，只给页面里最重要的那块 | `p-5` |
| `.btn` / `.btn-primary` / `.btn-ghost` / `.btn-warm` | 按钮 | 桌面 36 / 手机 44 |
| `.nav-item` | 顶部导航项 | 同上 |
| `.icon-btn` | 纯图标按钮 | 36×36 / 44×44 |
| `.chip` | 标签（状态、角色名） | 单行 |
| `.input` | 输入 | 与按钮等高 |

新增页面优先复用这几类；页面里出现 `px-3 py-2 text-sm` 这类临时组合，就是该提成组件类的信号。

## 4. 对白排版

```
[座位号] 说话人            时间
医疗舱 · 第 2 轮
台词正文，行高 1.7，最大约 40 个汉字一行。
```

- 座位号与时间戳等宽；说话人用 `text-strong`；正文 `text-slate-200`。
- 主持人/系统消息整行降级为 `text-slate-400` + 左侧细线，不与玩家发言抢注意力。
- 「正在说」只有一处动效：省略号呼吸，`prefers-reduced-motion` 下静止。

## 5. 移动端验收脚本（DOM 量测）

```js
const seal = (sel) => [...document.querySelectorAll(sel)].map((el) => {
  const r = el.getBoundingClientRect()
  return { text: el.textContent.trim().slice(0, 12), h: Math.round(r.height), y: Math.round(r.y) }
})
seal('.nav-item, .icon-btn, select')
document.documentElement.scrollWidth - document.documentElement.clientWidth // 必须为 0
```

截不到图时以这份数据为准，并在汇报里注明「DOM 量测，非截图」。
