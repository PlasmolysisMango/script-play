# 剧本框架缺口登记

每导入一本剧本，把「原件规则」逐条对照现有能力矩阵；命中不了的登记在此。
**缺口只在批 0 集中落地**，之后批次原则上只登记不改架构，避免边做边改。

登记格式一条一张表：本子 / 页面 / 规则原文 / 缺的能力 / 建议字段。
